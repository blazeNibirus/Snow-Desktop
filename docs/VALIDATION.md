# Проверка версии 0.1.0

Локальная среда: 11 ноября 2026, Mac с Apple M5, 16 ГБ RAM, macOS 27.2, один встроенный дисплей 60 Гц. Это проверка первой рабочей версии, а не заявление о совместимости со всеми конфигурациями.

## Подтверждено локально

- Сборка Swift/AppKit-приложения и `.saver` с Command Line Tools.
- 12 сценариев физики, выполненных самостоятельным runner: интервал перекрытия, максимизированная область, посадка на поверхность, отсутствие пола по краям Dock, перекрытые сугробы, осыпание при закрытии, инерция, максимальная глубина, скорость, ограничение частиц/пробуждение, пассивный режим и полноэкранная маска накопления.
- Запуск настоящего `.app`, просмотр нативного popover, переключателей, ползунков и живого предпросмотра. Проверена компоновка на Retina: текст и элементы управления не обрезаются.
- Динамическая загрузка `.saver`, поиск principal class, start/animate/stop и рендер PNG-предпросмотра через `Tools/SaverProbe.m`.
- SVG-иллюстрации отрендерены и просмотрены.

## Ресурсы

30-секундная серия с работающим приложением и открытыми настройками:

| Метрика | Результат |
| --- | --- |
| Физический footprint приложения | 26 МБ |
| Бюджет 0,5% на этой машине | 81 МБ, после округления вниз |
| Среднее значение CPU из выборок `ps` | 6,91% одного ядра |
| Максимальное значение CPU из выборок `ps` | 10,4% одного ядра |
| Максимальный RSS с общими страницами | 92,2 МБ |
| Частота тестового дисплея | 60 Гц |

`phys_footprint`, RSS и память WindowServer — разные показатели. Целевой бюджет относится к физическому footprint процесса; в этих измерениях он соблюдён. RSS включает общие страницы системных библиотек и выше бюджета. Суммарная память WindowServer и энергопотребление отдельно не измерены. Нулевой нагрузки нет. Результаты не переносятся автоматически на другой Mac, несколько 5K-дисплеев или иную версию macOS.

## Что ещё требует проверки пользователем / на других устройствах

- Реальные границы и увеличение Dock после предоставления «Универсального доступа». На момент локального замера разрешение приложению не было выдано. Механика конечных полок и падения по краям покрыта тестами, взаимодействие с конкретным Dock этим не подтверждается.
- Запуск выбранной заставки в системном хосте при заблокированной сессии, особенно после обновлений macOS. Проверка загрузки модуля и локальный рендер не заменяют такой тест. На защищённом поле пароля эффект не поддерживается.
- Первый перезапуск с включённым системным автозапуском; решение о допуске принимает macOS.
- Дисплеи 120/144/240 Гц, несколько мониторов, Intel, вертикальное расположение экранов, авто-скрытие и несколько Spaces, Stage Manager / Mission Control.
- Длительный прогон, энергопотребление, нотариализация и установка на другом компьютере.

На машине с одними Command Line Tools `swift test` недоступен из-за отсутствующего XCTest; тот же набор из 12 сценариев успешно выполнен через `Scripts/test-physics.sh`. GitHub Actions использует полный Xcode и дополнительно запускает XCTest.
